# Firmware docs

All documentation lives in the [gripora-docs](https://github.com/gripora-project/gripora-docs) repository,
published at <https://doc.gripora.org>: the user guides, the CLI reference, and the developer material under
Contributing (code guidelines, coding style and the
[Technical Reference](https://doc.gripora.org/contributing/tech/)).

This directory intentionally holds nothing else. Do not add documents here; add them to gripora-docs and, if
source code depends on one, link to it by URL. See [AGENTS.md](../AGENTS.md) for the working rules.
